# TwoPlateDispense — ทดสอบจานหมุน 2 จานพร้อมกัน

sketch เดี่ยวสำหรับสอบเทียบกลไก ยังไม่เกี่ยวกับ Wi-Fi หรือ server
เมื่อได้ค่ามุมและเวลาที่ใช้จริงแล้ว ค่อยย้ายค่าเหล่านั้นไปใส่ใน `ESP32_Main/config.h`

## ต่างจาก sketch ทดสอบเดิมอย่างไร

sketch เดิมใช้ `delay()` รอ servo หมุนถึงตำแหน่ง จานที่สองจึงต้องรอจานแรกจบก่อนเสมอ
ไฟล์นี้เปลี่ยนเป็น state machine ที่คุมด้วย `millis()` ทั้งหมด **ในลูปไม่มี `delay()` เลย**
จานทั้งสองจึงเดินลำดับของตัวเองทับเวลากันได้จริง และปรับมุม/เวลาแยกจานได้

## การต่อสาย

DRV8833 หนึ่งตัวมี 2 ช่อง (A และ B) พอดีกับมอเตอร์สั่น 2 ตัว ไม่ต้องเพิ่มบอร์ด

| หน้าที่ | จาน 1 | จาน 2 | หมายเหตุ |
|---|---|---|---|
| สายสัญญาณ Servo | GPIO18 | GPIO19 | ตรงกับ `SERVO_PINS` ใน `config.h` |
| DRV8833 IN1 (PWM คุมความแรง) | GPIO13 | GPIO26 | ขา `AIN1` / `BIN1` |
| DRV8833 IN2 (ทิศทาง/เบรก) | GPIO4 | GPIO16 | ขา `AIN2` / `BIN2` |

- `GND` ของ DRV8833, แหล่งจ่ายไฟ และ ESP32 ต้องต่อถึงกันทั้งหมด
- ขา `SLP` / `nSLEEP` ของ DRV8833 ต้องเป็น HIGH (หลายบอร์ดต่อค้างมาให้แล้ว)
- `VM` ของ DRV8833 รับไฟมอเตอร์ ส่วนตรรกะรับ 3.3V จาก ESP32 ได้โดยตรง

### เรื่องไฟเลี้ยง

สอง servo 270° หมุนพร้อมกันกินกระแสช่วงออกตัวสูงกว่าตัวเดียวมาก
ถ้าจ่ายไฟจากพอร์ต USB อย่างเดียวมักตกจนบอร์ดรีบูต ให้ใช้อะแดปเตอร์ 5V ที่จ่ายได้อย่างน้อย 3A

> **ห้ามเสียบอะแดปเตอร์ 5V เข้าขา VIN/5V ของ ESP32 พร้อมกับสาย USB** เพราะไฟจะย้อนเข้าหากัน

มอเตอร์สั่นส่วนใหญ่เป็นรุ่น 3V ถ้า `VM` เป็น 5V ต้องคุมด้วย PWM ไม่ให้เกินราวๆ 150/255
ค่าเริ่มต้น `VIB_SPEED = 70` อยู่ในช่วงที่ปลอดภัยแล้ว

## วิธีใช้

1. เปิด `TwoPlateDispense.ino` ด้วย Arduino IDE เลือกบอร์ด ESP32 แล้วอัปโหลด
2. เปิด Serial Monitor ที่ **115200**
3. พิมพ์คำสั่ง:

| คำสั่ง | ผล |
|---|---|
| `1` / `2` | หมุนจานนั้น 1 รอบ |
| `b` | หมุนทั้งสองจานพร้อมกัน 1 รอบ |
| `r` | หมุนทั้งสองจานพร้อมกัน `CYCLES_PER_RUN` รอบ |
| `s` | หยุดทุกจานและกลับตำแหน่งพักทันที |

**ทดสอบโดยยังไม่ใส่ยาก่อน** เพื่อดูว่าจานไม่ติดขัดและ servo ไม่ชนสุดทาง

## ค่าที่ต้องปรับให้ตรงกับกลไกจริง

อยู่รวมกันด้านบนของไฟล์:

| ค่า | ความหมาย |
|---|---|
| `REST_ANGLE[]` | ตำแหน่งพักของแต่ละจาน |
| `DISPENSE_ANGLE[]` | ตำแหน่งที่กวาดยาให้ตก แยกทิศทางรายจานได้ |
| `TRAVEL_MS` | เวลาที่ servo ใช้หมุนจนถึงตำแหน่ง — **ต้องวัดจากของจริง** ถ้าตั้งสั้นไป มอเตอร์จะถูกเบรกก่อนจานหมุนถึง ยาจะไม่ตก |
| `VIB_SPEED` | ความแรงสั่น 0–255 (ใช้ได้จริงราว 60–130) |
| `VIB_KICK_MS` | ช่วงกระตุกเต็มกำลังให้ตุ้มถ่วงออกตัว |

## ทำไมมอเตอร์ถึงสั่งผ่าน `analogWrite` ตลอด

ทั้งสามสถานะใช้ `analogWrite` ที่ขา IN1 เสมอ ไม่สลับไป `digitalWrite`:

| สถานะ | IN1 | IN2 |
|---|---|---|
| สั่นเบา | PWM `VIB_SPEED` | LOW |
| เบรกล็อกแกน | PWM 255 | HIGH |
| ปล่อยอิสระ | PWM 0 | LOW |

บน ESP32 การ `analogWrite` จะผูกขานั้นเข้ากับ LEDC ถ้าเรียก `digitalWrite` ที่ขาเดิมภายหลัง
สัญญาณ PWM อาจยังค้างอยู่ทำให้คุมไม่ได้ตามคาด การใช้ `analogWrite(255)` แทน `digitalWrite(HIGH)`
ให้ผลเหมือนกันแต่ไม่มีปัญหานี้

## ข้อควรรู้เรื่อง LEDC timer

`setup()` จอง LEDC timer ให้ ESP32Servo แค่ 2 ตัวตามจำนวน servo
ถ้าจองครบ 4 ตัวตามตัวอย่างทั่วไป จะไม่เหลือ timer ให้ `analogWrite` และมอเตอร์สั่นจะไม่ทำงาน

## ใช้กับ Arduino Uno

รองรับด้วย โดย sketch จะเลือกขาให้เองเมื่อไม่ได้คอมไพล์สำหรับ ESP32:
servo ขา 9/10, IN1 ขา 5/6, IN2 ขา 7/8

ไลบรารี `Servo` ของ Uno ยึด Timer1 ไว้ ทำให้ `analogWrite` ที่ขา 9 และ 10 ใช้ไม่ได้
จึงต้องแยกขา servo กับขา PWM ของมอเตอร์ออกจากกันแบบนี้
