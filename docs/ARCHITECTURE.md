# Architecture and wiring

## ภาพรวมระบบ

```text
Website / schedule
        |
        v
ESP32 Main ---- RTC DS1307
    |  |-------- LCD 1: เวลาปัจจุบัน
    |  |-------- LCD 2: ยาและรอบถัดไป
    |
    | I2C: GPIO21 SDA, GPIO22 SCL
    v
Bidirectional Logic Level Shifter (3.3V <-> 5V)
    |
    | I2C: A4 SDA, A5 SCL
    v
Arduino Nano (address 0x10)
    |-------- D7 -> Servo จานยา 1
    |-------- D8 -> Servo จานยา 2
    |-------- D9 -> Servo จานยา 3
    |-------- input <- IR 1: ตรวจเม็ดยาตกจากจาน 1
    |-------- input <- IR 2: ตรวจเม็ดยาตกจากจาน 2
    `-------- input <- IR 3: ตรวจเม็ดยาตกจากจาน 3
```

LCD ทั้งสองจอและ DS1307 อยู่บน I²C bus เดียวกัน จึงต้องมี address ไม่ซ้ำกัน
ขา input สำหรับ IR ยังไม่ได้กำหนด รอยืนยันรุ่นและชนิดเอาต์พุตของเซนเซอร์

## Protocol ระหว่าง ESP32 กับ Nano

ESP32 ส่งข้อมูล 3 bytes ต่อคำสั่ง:

| Byte | ค่า | ความหมาย |
|---:|---|---|
| 0 | `0x01` หรือ `0x02` | `DISPENSE` หรือ `STOP` |
| 1 | `0`–`3` | หมายเลขจานยา; `0` ใช้กับ `STOP` |
| 2 | `0`–`9` | จำนวนเม็ด; `0` ใช้กับ `STOP` |

ตัวอย่าง `01 02 03` คือสั่งจานยา 2 จ่าย 3 เม็ด

## ระบบจ่ายไฟ

```text
Adapter +5V -> Fuse -> Main switch -> +5V bus
Adapter GND --------------------------> GND bus

+5V/GND bus --+--> Servo 1
              +--> Servo 2
              +--> Servo 3
              +--> Nano (เข้าขา 5V ไม่ใช่ VIN)
              +--> ESP32 dev board (เข้าขา 5V/VIN ตามรุ่นบอร์ด)
              +--> โมดูล 5V ที่ยืนยันสเปกแล้ว

1000uF capacitor: ขา + ไป +5V bus, ขา - ไป GND bus
```

Logic Level Shifter ใช้แปลงระดับสัญญาณเท่านั้น ไม่ได้ใช้เป็นแหล่งจ่ายไฟให้ Nano หรือ ESP32

## IR สำหรับตรวจจับวัตถุ

ผู้ใช้ยืนยันว่ามีเซนเซอร์แสงอินฟราเรด (IR) จำนวน 3 ตัวในระบบ เมื่อวันที่ 13 กันยายน 2026
แต่ละตัวตรวจเม็ดยาที่ตกจากจานยาของตนเอง โดยให้ Nano อ่านค่าและจัดการร่วมกับ Servo ของจานนั้น

| ชุดจ่ายยา | Servo (ขา Nano) | เซนเซอร์ | หน้าที่ |
|---|---|---|---|
| จาน 1 | D7 | IR 1 | ตรวจเม็ดยาตกจากจาน 1 |
| จาน 2 | D8 | IR 2 | ตรวจเม็ดยาตกจากจาน 2 |
| จาน 3 | D9 | IR 3 | ตรวจเม็ดยาตกจากจาน 3 |

ยังต้องยืนยันรุ่น แรงดัน ชนิดเอาต์พุต และระดับสัญญาณเมื่อตรวจพบวัตถุ
ก่อนกำหนดขาและเพิ่มโค้ดอ่านค่า ตำแหน่งยึดและระยะตรวจจับต้องทดสอบกับกลไกจริง

ขณะนี้ firmware ยังไม่มีโค้ดอ่าน IR: จำนวนที่ส่งในคำสั่งเป็นจำนวนรอบการขยับ Servo
และยังไม่ได้ยืนยันจำนวนเม็ดยาที่ตกจริงด้วยเซนเซอร์

## ส่วนที่ยังต้องยืนยันกับกลไกจริง

- Pulse width ตำแหน่งพักและตำแหน่งปล่อยของ Servo ทั้งสามตัว
- จำนวนองศาต่อหนึ่งเม็ด
- รุ่น สัญญาณเอาต์พุต และระยะติดตั้งของ IR sensor ทั้ง 3 ตัวที่ตรวจเม็ดยาตกจานละ 1 ตัว
- ความจำเป็นของมอเตอร์สั่น, motor driver และประตูทางออกเสริม
- การใช้ ESP32-CAM; ยังไม่รวมใน firmware ชุดปัจจุบัน

ห้ามใช้ค่ามุมตัวอย่างกับยาโดยตรง ควรทดสอบ Servo ทีละตัวแบบไม่มีโหลดและจำกัดช่วง pulse ก่อนเสมอ
