ดและคัว
มสอดคัล องของระบบ
ตารางที่ 3.5 กรณีตั้งค่าไม่สำเร็จและพฤติกรรมที่พบ
เงื่อนไข พฤติกรรมจากโค้ด
ชื่อหรือรหัส Wi-Fi ไม่ถูกต้องรอเชื่อมสูงสุด 30 วินาที แล้วแจ้ง WIFI FAILED; ค่าเดิมไม่ถูกลบหากยัง
ไม่เชื่อมสำเร็จ
รหัสตั้งค่าผิดหรือหมดอายุแจ้ง PAIR FAILED; กลับไปสร้างรหัสใหม่จากเว็บไซต์
เครื่องมีเจ้าของอื่น เซิร์ฟเวอร์ปฏิเสธ; เจ้าของเดิมต้องยกเลิกการจับคู่ก่อน
API key ไม่ถูกต้อง แจ้ง BAD API KEY; ต้องให้ผู้ดูแลตรวจข้อมูลประจำเครื่อง
ตรวจรหัสบ่อยเกินโควตา HTTP 429 และ RATE LIMITED; หยุดลองอัตโนมัติและแจ้งให้รอ
ติดต่อเซิร์ฟเวอร์ไม่ได้แจ้ง NO SERVER และลองซ้ำ; เมื่อเกินประมาณ 120 วินาทีหยุดรอบการ
ลอง
บันทึก NVS ไม่สำเร็จ แจ้ง SAVE FAILED ในขั้นยืนยันสำเร็จ; ไม่ควรถือว่าค่าคงอยู่หลังรีเซ็ต
หาก Wi-Fi บันทึกแล้วแต่จับคู่ไม่ผ่าน เฟิร์มแวร์อาจปิดโหมดตั้งค่าหลังเวลาผ่อนผัน 20 วินาทีเพื่อกลับไป
ทำงาน การไม่มีโทรศัพท์เปิดหน้าตั้งค่าเกินห้านาทีจะออกจากโหมดเมื่อมีเครือข่ายบันทึกแล้ว จึงไม่ควรสรุป
ว่าทุกความล้มเหลวจะเปิดหน้าแก้ไขไว้ตลอด
ค่าเริ่มต้นของเฟิร์มแวร์คำนวณรหัสผ่าน AP เป็นเลขฐานสิบหกแปดตัว ส่วนบริการ setupAccess ที่
ตรวจสร้างรหัสยาว 16 ตัว หน้า QR รุ่นปัจจุบันไม่แสดงรหัสนี้และให้ดู LCD แต่ข้อความบางหน้าและ
เอกสารยังกล่าวถึงสติกเกอร์ ความต่างนี้ต้องตรวจให้ตรงกันเมื่อเตรียมฉลากและทดสอบโทรศัพท์จริง
QR เป็นลิงก์สาธารณะประจำอุปกรณ์ รหัสตั้งค่าเป็นสิทธิชั่วคราวในการจับคู่ API key เป็นข้อมูลลับ
ประจำเครื่อง และ Wi-Fi SSID/รหัสผ่านเป็นข้อมูลเครือข่ายบ้าน ข้อมูลทั้งสี่ชนิดมีหน้าที่ต่างกันและไม่ใช้
