7. ESP32 ทดลองเชื่อม Wi-Fi บ้าน เมื่อเชื่อมได้และเขียน NVS สำเร็จจะบันทึกข้อมูล Wi-Fi ทันที จาก
นั้นส่งรหัสตั้งค่าไปยืนยันกับเซิร์ฟเวอร์โดยใช้ API key ของเครื่อง จึงเป็นสองเงื่อนไขแยกกัน
8. เมื่อเซิร์ฟเวอร์ตอบสำเร็จและการบันทึก Wi-Fi สำเร็จ เครื่องแสดง PAIRED, DONE และหน้าตั้งค่า
แจ้งสำเร็จ เครือข่ายตั้งค่าปิดหลังประมาณสิบวินาที แล้วร้องขอซิงก์ทันที
9. โทรศัพท์กลับไปใช้ Wi-Fi บ้านหรือข้อมูลมือถือ เปิดแท็บเว็บไซต์เดิม เว็บไซต์ตรวจสถานะเป็นระยะและ
แสดงสำเร็จเมื่อการจับคู่ถูกยืนยันและมี last_seen_at ใหม่ไม่น้อยกว่าเวลายืนยันการจับคู่
